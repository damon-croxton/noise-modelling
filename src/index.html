Building heights from LiDAR

No LiDAR loaded. Uses class 6 (building) points for roof levels; class 2 (ground) builds the terrain if no DEM is loaded. The file is read locally – nothing is uploaded.

Buildings from free data

Footprints: OpenStreetMap. Heights: OSM height → levels × 3 m → typical height for the building type (dashed outline = estimated). A DSM (roof surface) overrides estimates.

No DEM loaded – ground is flat at RL 0.

Uses the time period set under Model. Each building is assessed on its exposed façades at 1.5 m above each floor; the worst point per floor is reported.

Scenario

Screening and planning aid only. It does not replace an assessment by a qualified acoustic consultant and is not a validated compliance model. Plant levels and assessment defaults come from Transport for NSW documents – verify them against the current client strategy and replace them with project data where available. The DEM and LiDAR are not saved in the JSON – reload them after loading a scenario.
